# 🚀 Aivora — AI-Powered Conversational Assistant Platform

**Aivora** is a modern full-stack AI assistant platform designed to deliver intelligent, real-time conversational experiences using large language model integration. The system demonstrates how scalable web architecture can be combined with AI services to build production-ready conversational applications.

It enables users to interact naturally with an AI assistant capable of answering queries, generating content, assisting workflows, and maintaining contextual conversations through a responsive and intuitive interface.

# 🧠 System Architecture Overview

Aivora follows a clean **client-server architecture** where the frontend communicates with a Node.js backend responsible for securely interacting with AI services.

Frontend handles:

* user interaction
* UI rendering
* chat state management

Backend handles:

* API routing
* AI request processing
* environment security
* response formatting

# ⚙️ Installation Guide

### Step 1: Clone Repository

git clone https://github.com/Karxn-saini07/Aivora

---

### Step 2: Navigate Into Project

cd Aivora

---

### Step 3: Install Dependencies

Install frontend dependencies

cd frontend
npm install

Install backend dependencies

cd ../backend
npm install

---

# 🔑 Environment Variables Setup

Create a `.env` file inside the backend directory
---

# ▶️ Running the Application

Start backend server

cd backend
nodemon server.js

Start frontend application

cd frontend
npm run dev

Application will run locally on:

Frontend → http://localhost:5173
Backend → http://localhost:5000
